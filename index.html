What is LDES?

Linked Data Event Streams (LDES) is an open specification for publishing an append-only collection of immutable members as Linked Data. Members can describe events, observations, or successive versions of a record. Consumers can copy the available data, then follow new members as they are published.

Publish once. Support many uses.

Publisher provides a common source without having to build an API for every use case.

  1. Publish changes. Add new members instead of overwriting existing ones. Use shared RDF vocabularies to describe the data.
  2. Copy and follow. Clients traverse linked pages over HTTP and check for new members, reusing cached responses where possible.
  3. Build your own view. Maintain a local database, search index, or API, and process updates at your own pace.

LDES uses TREE links to let clients discover and navigate pages of members. Views can be fragmented by time or other properties; the stream itself is not necessarily delivered in chronological order. How far a client can go back depends on the publisher’s retention policy.

Developed in the SEMIC community, LDES gives publishers and consumers a shared contract for exchanging changing data. Read the specification →

Who supports and implements LDES

Interoperable Europe

Interoperable Europe, the European Commission programme for cross-border digital public services, is the main current funder and maintainer of the LDES specification.

  • Flanders (Vlaamse Smart Data Space)

Implementers and early adopters

A growing list of organisations publish or consume LDES in production. A few examples:

  • City of Ghent (CoGhent)
  • VLIZ (Flanders Marine Institute)
  • Rijksmuseum
  • European Union Agency for Railways
