LDES examples

A set of examples of LDES in practice: collection records, catalog updates, marine data, and observations. These are starting points for exploring what you can publish and build with LDES, rather than an exhaustive list.

The SEMIC LDES implementation reports explain the design choices behind real deployments. For a closer look at harvested data, visit the LDES Explorer.

How others use LDES

Keep data catalogs in sync
Catalog publishers can share changes so harvesters can update their copies incrementally. The BOSA report follows the Belgian federal catalog from publication to harvesting; the ERA report shows a pipeline that publishes catalog changes as static files.
Share cultural heritage collections
Museums and aggregators need to exchange new records, revisions, and deletions. The cultural heritage report describes how LDES and ActivityStreams support those exchanges, including versioning and retention choices.

Build a data space with OpenLDES

The OpenLDES community provides tools for publishing, consuming, and republishing streams. The Flanders Smart Data Space is a documented example of using LDES to exchange data across organisations. Explore the OpenLDES tooling and the architecture described in the paper.
