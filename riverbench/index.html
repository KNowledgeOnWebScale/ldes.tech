RiverBench as LDES

RiverBench is an open, community-driven benchmark suite of RDF streams. Here, 10 of its 15 datasets are described as a Linked Data Event Stream (LDES) 2.0, so that you can replicate them with an LDES client.

Every LDES is a small static root page (root.trig) on this website, hosted on GitHub Pages. Its one page is the Jelly-RDF file with the first 10 000 elements of the dataset, which RiverBench itself hosts: this website does not copy any data. In every Jelly file, one message is one member of the LDES. The catalog (catalog.ttl, DCAT) lists the datasets with their metadata from RiverBench, and every LDES as a distribution of its dataset. The files are generated by scripts/generate-riverbench.mjs, which also checks every description against the data.

Datasets with an LDES

  • ASSIST-IoT weather (graphs variant)

    This is a timestamped stream of weather data collected with a Davis Vantage Pro 2 weather station installed on the building of the Systems Research Institute, Polish Academy of Sciences. The data was collected during the ASSIST-IoT Horizon 2020 project. The station measured several different weather parameters and transmitted them in real time at regular intervals. The measurements have rich annotations with the SOSA/SSN and OM 2.0 ontologies. The stream is very regular and the elements only differ by numeric values and timestamps. This is the graph variant, which is a timestamped graph stream compatible with the RSP Data Model.

    License: CC-BY-4.0. 10 000 of 701 278 stream elements (704 KB Jelly file, jelly_10K.jelly.gz), members ordered on the timestamp prov:atTime, from 2023-01-02T15:36:37.065535 until 2023-01-03T19:36:28.505900 (exclusive).

    https://ldes.tech/riverbench/assist-iot-weather-graphs/root.trig

    Member: the named graph of a message (with its timestamp). root.trig · RiverBench dataset page.

  • CityPulse traffic

    This is a processed subset of real traffic data published by the CityPulse EU FP7 project. The used dataset is 'Road Traffic Data', dataset-4. The dataset was processed to fix prefixes without a trailing '#' or '/'. The dataset consists of subsequent chronologically ordered substreams of observations from each sensor. See also the paper for more details.

    License: CC-BY-4.0. 10 000 of 4 382 599 stream elements (2.9 MB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/citypulse-traffic/root.trig

    Member: the subject of type sao:FeatureOfInterest of a message. root.trig · RiverBench dataset page.

  • CityPulse traffic (graphs variation)

    This is a variation of the citypulse-traffic dataset that was transformed into a stream of graphs, compliant with the RSP Data Model. The dataset is a processed subset of real traffic data published by the CityPulse EU FP7 project. The used dataset is 'Road Traffic Data', dataset-4. The dataset was processed to fix prefixes without a trailing '#' or '/'. It consists of subsequent chronologically ordered substreams of observations from each sensor. See also the paper for more details.

    License: CC-BY-4.0. 10 000 of 4 382 599 stream elements (3.0 MB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/citypulse-traffic-graphs/root.trig

    Member: the named graph of a message (with its timestamp). root.trig · RiverBench dataset page.

  • EU Digital Agenda Key Indicators

    The dataset of EU Digital Agenda Key Indicators contains statistical information about the European information society. The dataset is composed of a series of statistical observations with various properties and a very regular structure.

    License: CC-BY-4.0. 10 000 of 1 440 415 stream elements (199 KB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/digital-agenda-indicators/root.trig

    Member: the one subject of a message. root.trig · RiverBench dataset page.

  • Muziekweb

    The dataset consists of the main graph of Muziekweb, a high-quality Dutch knowledge base about music, containing information about artists, CD, LPs, and more. The knowledge base is richly annotated and contains plentiful links to external resources.

    License: ODC-By-1.0. 10 000 of 2 450 357 stream elements (781 KB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/muziekweb/root.trig

    Member: the one subject of a message. root.trig · RiverBench dataset page.

  • Nanopublications

    Nanopublications are small units of publishable information, used for scientific results and more. This dataset is based on a subset of a dump of all available nanopublications as of April 5, 2018. Only the first 5M of freely-licensed nanopubs were included. Each nanopub consists of several RDF graphs and thus is an RDF dataset. The included data is primarily from the biomedical domain. More information: paper, website.

    License: CC-BY-SA-3.0. 10 000 of 5 000 000 stream elements (2.3 MB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/nanopubs/root.trig

    Member: the subject of type np:Nanopublication of a message (four named graphs). root.trig · RiverBench dataset page.

  • OfficeGraph

    OfficeGraph is a real-world dataset of measurements from 444 IoT devices taken over 11 months. The devices are made up of 17 different sensor models which measure different properties. The data was collected in a Dutch 7-story office building and consists of about 90 million RDF triples. See also the paper for more details.

    License: CC-BY-4.0. 10 000 of 14 930 478 stream elements (181 KB Jelly file, jelly_10K.jelly.gz), members ordered on the timestamp saref:hasTimestamp, from 2022-02-28T23:59:00 until 2022-03-01T05:47:01 (exclusive).

    https://ldes.tech/riverbench/officegraph/root.trig

    Member: the subject of type saref:Measurement of a message. root.trig · RiverBench dataset page.

  • OpenAIRE LOD graph

    OpenAIRE LOD was a service that exported data from the OpenAIRE information space in RDF format, using Linked Open Data principles. The data was exported to Zenodo, with the last dump dated at March 3, 2021. This dataset consists of the "result" subset of the OpenAIRE LOD graph, including scientific results such as publications.

    License: CC0-1.0. 10 000 of 2 000 000 stream elements (3.0 MB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/openaire-lod/root.trig

    Member: the subject of type lod:ResultEntity of a message. root.trig · RiverBench dataset page.

  • OpenStreetMap Denmark (osm2rdf)

    The dataset is based on datasets that were derived from OpenStreetMap data using the osm2rdf tool. It includes information about each element which is of type node (osm:node), way (osm:way) or relation (osm:relation). Nodes are a core concept in OSM and they represent a single point in space defined by geographic coordinates. A node itself can describe for example a city, town, road junction, post box etc. A way is line, represents linear features on the ground - like a road. It consist of an ordered node list. A relation is a colection of the three core elements: nodes, ways and relations. Each element contains all atributes associated with it.

    License: ODbL-1.0. 10 000 of 2 030 923 stream elements (2.5 MB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/osm2rdf-denmark/root.trig

    Member: the one subject with an rdf:type of a message. root.trig · RiverBench dataset page.

  • Politiquices

    Support and opposition relations extracted from news articles archived in Arquivo.pt. The dataset describes news articles in Portuguese and the presented political stances. Dataset source, more information about the project (Portuguese).

    License: CC-BY-4.0. 10 000 of 17 773 stream elements (1.4 MB Jelly file, jelly_10K.jelly.gz), members in the order of the file (implicit order: there is no timestamp to order on).

    https://ldes.tech/riverbench/politiquices/root.trig

    Member: the subject with a dc:title (the news article) of a message. root.trig · RiverBench dataset page.

Datasets without an LDES

These datasets are in the catalog, but could not be described faithfully as an LDES 2.0.

  • ASSIST-IoT weather (triples variant)

    This is a timestamped stream of weather data collected with a Davis Vantage Pro 2 weather station installed on the building of the Systems Research Institute, Polish Academy of Sciences. The data was collected during the ASSIST-IoT Horizon 2020 project. The station measured several different weather parameters and transmitted them in real time at regular intervals. The measurements have rich annotations with the SOSA/SSN and OM 2.0 ontologies. The stream is very regular and the elements only differ by numeric values and timestamps.

    License: CC-BY-4.0. 701 278 stream elements in the full dataset.

    No LDES: Every element is a set of triples in the default graph with about 30 subjects: ten observations and their sensor, feature of interest and properties. The feature of interest, the sensor and the properties are the same in all elements, and no class or property singles out one subject with an IRI that is unique to the element. LDES 2.0 cannot identify the members (ldes:memberGraph, ldes:memberType and ldes:memberPath all need one identifier per message). The graph variant (assist-iot-weather-graphs) has an LDES. RiverBench dataset page.

  • DBpedia Live

    DBpedia Live was a real-time service that monitored edits on Wikipedia and published a stream of changes to the DBpedia knowledge graph. This dataset contains only the "added" triples in the stream, so it does not include deletes or other types of changes. Only one month (January 2014) is covered at the moment, but the dataset can be easily expanded in the future (the service stopped functioning in 2021). The stream's elements are irregular in size, depending on the volume of traffic on Wikipedia at a given moment and how the DBpedia Live service was able to cope with it. See also the paper.

    License: CC-BY-SA-3.0. 166 204 stream elements in the full dataset.

    No LDES: The smallest Jelly distribution that RiverBench offers for this dataset (10K elements) is 69.9 MB: too large to read in a browser. RiverBench dataset page.

  • Linked Observation Data – Katrina

    The Katrina dataset from the Linked Observation Data collection by the Kno.e.sis Center describes weather measurements from many weather stations across the US during the Katrina hurricane. See more details on LOD Cloud and the original website (Internet Archive). See also the paper.

    License: CC-BY-3.0. 5 893 763 stream elements in the full dataset.

    No LDES: Elements have between 1 and 13 subjects (observations with their time instants, and independent annotations) and no class or property is shared by exactly one subject of every element, so LDES 2.0 cannot identify the members. RiverBench dataset page.

  • LinkedSpending

    This is a subset of the LinkedSpending dataset (LS package 2013-9), which contains government spending information from around the world. The dataset uses the RDF Data Cube vocabulary. Only the spending observations were kept in this subset, extra contextual information was discarded. See the website and the paper for more details.

    License: PDDL-1.0. 2 477 552 stream elements in the full dataset.

    No LDES: Every element describes one subject, but 43 of the first 10 000 elements describe a subject that an earlier element described already (for example the description of a dataset, split over two elements), so the subject cannot be the identifier of the member: two members would have the same identifier. RiverBench dataset page.

  • YAGO annotated facts

    This is a subset of the YAGO 4 knowledge base (paper), based on Wikidata, version from February 24, 2020. This dataset includes only the fact annotations in RDF-star, that is facts about facts. Each stream element corresponds to one item in Wikidata.

    License: CC-BY-SA-3.0. 617 768 stream elements in the full dataset.

    No LDES: The Jelly files of this dataset use RDF-star, which the Jelly decoder of the ldes-client (rdfjs-jelly 0.2.0) does not support, so the file cannot be read as an LDES page. RiverBench dataset page.

Consume them

With the ldes-client, give it the URL of a root page:

npx ldes-client https://ldes.tech/riverbench/assist-iot-weather-graphs/root.trig

The client prints one RDF message per member. Add --comment to see what the LDES says about every member. Support for LDES 2.0 in the client is experimental: it follows the evolving LDES 2.0 proposal, and the terms and behavior used here may change. The descriptions on this page change with it.
